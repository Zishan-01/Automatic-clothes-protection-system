
# Automatic Clothes Protection System

## Project Overview
The Automatic Clothes Protection System is an Arduino-based IoT project designed to protect clothes from unexpected rainfall. The proposed system uses a rain sensor to detect rain and a controller to initiate a protective response.

## Objectives
- Detect rainfall using a rain sensor.
- Automate the clothes protection process.
- Reduce the need for manual monitoring.
- Provide a foundation for future smart-home integration.

## Proposed Components
- Arduino microcontroller
- Rain sensor module
- Motor and compatible motor driver
- Connecting wires and power supply
- Mechanical clothes rack

Note: Confirm the component list against the actual prototype.

## Working Principle
1. The rain sensor monitors the surrounding conditions.
2. When rain is detected, the Arduino processes the sensor signal.
3. The controller can activate a motor driver to move the rack towards a sheltered area.
4. Optional return-to-drying functionality can be added when conditions become dry.
